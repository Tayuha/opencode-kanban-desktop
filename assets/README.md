# README images

Drop the accepted Desktop screenshots here with these names:

| File | View |
|---|---|
| `board.png` | Board with columns, cards, tags, and counts |
| `detail.png` | Detail view of a task with a real worktree/session, status, todos, and changes |
| `task-dialog.png` | New-task dialog including the worktree/open/prompt controls |
| `composer-pill.png` | Composer pill showing running tasks |
| `edit-task.png` | Optional: edit-task dialog |

Use PNG. Cropping the panel is fine; keep text readable. The README links will be added after the
files exist.
